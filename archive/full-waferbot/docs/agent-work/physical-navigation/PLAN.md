## Architecture and safety decisions
Use src/waferbot as a standalone physical adapter and hardware-independent navigation/control Python package; ROS is optional and no existing simulation was found. Use stdlib JSON configuration/maps and minimal dependencies (smbus2 only for physical hardware). Package CLI waferbot with pyproject.toml. Keep pure planner and geometry independent of I2C. Motor values are bounded PWM, never equated to m/s without explicit calibration. Driver protocol must trace to existing vendored source; correct its swallowed exceptions in an independent narrow adapter. Import and construction must not move motors.

Use fresh, debounced observations with monotonic time; ambiguous middle bits do not prove switching. Edge following uses all four sensors with bounded recovery, deadlines, and finally-stop. The switch FSM needs route authorization plus independently confirmed source location, stable opposite-edge evidence and independent destination localization. Manual confirmation must happen with motors stopped; no blocking prompt while moving. Interfaces permit marker localizers and simulated fixtures. Arrival never follows from elapsed time or edge polarity. Example map is visibly illustrative, explicitly labels direction/edge separately, and must be acknowledged/replaced for physical execution.

Central safety states and typed faults, latched emergency stop, best-effort all-wheel stops even after an I2C error. Motion requires explicit operator arming; CLI defaults mock and physical requires a mode selection and prompt. Motion deadlines and software watchdog are required; document that power loss/process kill/I2C failure needs physical motor power cutoff, since no independent controller watchdog is verified. Handle Ctrl+C and exceptions. Provide process ownership/stop coordination so a second stop CLI cannot be immediately overwritten by a running controller. Hardware tests must not be claimed here.

Graph validation rejects invalid/nonfinite dimensions, speeds, unknown references/actions, incompatible edge actions and unsafe routes. Dijkstra is default. A* uses Euclidean distance / maximum speed only with metric consistency ensuring admissibility (otherwise zero). Costs include traversal and switch/dock overhead. Ordered mandatory waypoints must remain executable and enabled edges respected.
